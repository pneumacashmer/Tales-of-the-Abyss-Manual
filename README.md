# Tales-of-the-Abyss-Manual
A Manual + Save + Instructions for a Tales of the Abyss Manual for Archipelago

All Cities are Unlocked from the Start.
The Overworld and Search Points are all unlocked from the start.
Dungeons are each locked individually.
Use codes provided to force toggle boss fights for those checks.
Shops equipment is locked behind Progressive Gald Limits
There are over 500 Items and Checks covering chests, sidequests, and bosses.
Keep all characters except Luke on guard until they have been unlocked.
The level checks are based on the highest level of party member.
There are 2 alternative victory conditions.  One for beating the Final Boss requiring 4 items, and the Secret Boss requiring 6.

Given the nature of a JRPG, some chests may not be added and some sidequests may unintentionally be incompletable.
Do not activate the final cutscene before the final boss as it will lock out of various sidequests.

This Manual has a Specific Save File to use.  The memory card file ToTA Prepared Save.ps2 needs to be used to have a fresh save with a fully explorable world.
The Manual also has Boss Drops.  Using SLUS-21386-045D77E9.pnach as a cheat file, whenever you wish to challenge a certain boss.  Delete the "//" in front of the respective line.  Go to a new area, and fight a random encounter.  Early Game Bosses like the Liger Queen will only have specific party members active.
